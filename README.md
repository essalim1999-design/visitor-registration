# سجل الزائرات — الروضة الأولى بأحد المسارحة

نموذج ويب لتسجيل بيانات الزائرات، يرسل البيانات إلى Google Sheet عبر Google Apps Script.

## الملفات
| الملف | الوصف |
|------|-------|
| `index.html` | صفحة النموذج |
| `style.css` | التنسيقات |
| `app.js` | التحقق + الإرسال (`API_URL` في أعلى الملف) |
| `moe-logo.png` | شعار وزارة التعليم |
| `Code.gs` | كود الـ Apps Script (مرجع — يُلصق في محرر «برمجة التطبيقات» المرتبط بالشيت) |
